# Manufacturer and product names that must not appear in effect names, UI
# text, prompts, evaluation items or file names (AGENTS.md, hard rule 2).
# Read by tools/check-trademarks.py, which the `no-trademarks` pre-commit hook
# runs. The first part is copied from faust-pedalkit's tools/trademarks.txt so
# the two repositories refuse the same names; the second part adds names a
# player is likely to type when describing a sound.
#
# One name per line. Matching ignores case, spacing, hyphens, underscores and
# CamelCase, so "Sans Amp" also catches "SansAmp", "sans_amp" and "SANSAMP".
# A name only matches as a whole word: "Boss" catches "BossDrive" but not
# "emboss". Leave out names that are ordinary words (e.g. "Orange", "Rat",
# "Zoom", "Jazz Bass"), or the check will flag normal prose; list the product
# instead. Lines starting with # are comments.
#
# Decision-model projects (and their vendors) are named in docs/ and in the
# backend configuration, which are not scanned for content. They are kept out
# of prompts by review, not by this list, because the harness has to name the
# backend it calls.
